# clipbeam

Clip structured JSON beam payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/clipbeam/

## Install / run

```bash
git clone https://github.com/theworker02/clipbeam.git
cd clipbeam
node src/cli.js
node --test
```
